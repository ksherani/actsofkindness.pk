QUICK START (3 STEPS)

STEP 1: PREVIEW LOCALLY

IMPORTANT TIPS
================================================================================

1. BACKUP BEFORE CHANGES
   - Always keep a copy of original files
   - Make one change at a time
   - Test before deploying

2. MOBILE TESTING
   - Test on actual mobile device
   - Use F12 developer tools (mobile view)
   - Check form on mobile

3. FORMS
   - Forms currently log to console
   - For real submissions, see README.md
   - FormSubmit.co is easiest option (free)

4. PERFORMANCE
   - Website loads fast (uses CDN)
   - No database needed
   - No backend required
   - Works on any hosting

5. FONTS
   - Cormorant Garamond = headings (elegant)
   - Lato = body text (clean)
   - Both from Google Fonts (always available)

6. COLORS
   - Emerald green (#10b981) = primary
   - Teal (#0d9488) = secondary
   - Uses gradients for depth
   - Professional, non-profit appropriate

================================================================================
TROUBLESHOOTING
================================================================================

WEBSITE NOT LOADING?
→ Check index.html is in public_html folder
→ Check file permissions (644 for files, 755 for folders)
→ Clear browser cache (Ctrl+F5)

STYLES NOT SHOWING?
→ Check css/styles.css file is uploaded
→ Verify css/ folder exists in public_html
→ Clear cache and refresh

FORM NOT WORKING?
→ Set up form handler (see README.md)
→ Try FormSubmit.co (easiest)
→ Check browser console for errors (F12)

MOBILE LOOKS WRONG?
→ Check viewport meta tag in HTML (already included)
→ Test with F12 mobile view
→ Test on actual phone

ANIMATIONS NOT SMOOTH?
→ Clear browser cache
→ Try different browser
→ Check GSAP library loads (F12 console)

SOCIAL LINKS NOT WORKING?
→ Check URLs are complete (https://...)
→ Verify account handles are correct
→ Test each link individually
